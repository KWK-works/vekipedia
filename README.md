# Vekipedia - 偏見的地元民百科事典

## 🎯 プロジェクト概要

**Vekipedia**は、日本全国47都道府県の「地元民しか分からない」偏見的あるあるネタを集めた、参加型のWiki百科事典サイトです。土屋賢二風の軽妙で愛情のこもった文体で、各地の文化や習慣を面白おかしく紹介します。

### 🌟 主な特徴

- **47都道府県対応**: 全国の地元ネタを網羅
- **参加型システム**: ユーザーが自由に記事を投稿・編集可能
- **カテゴリ分類**: スポット、交通、言語、文化、グルメなど10カテゴリで整理
- **検索・フィルター**: 都道府県別、カテゴリ別、キーワード検索に対応
- **レスポンシブデザイン**: PC・スマートフォン両対応
- **リアルタイム統計**: 記事数、対応都道府県数、いいね数などを表示

## 🔧 技術仕様

- **Font Awesome**: アイコンライブラリ

- **RESTful Table API**: データ操作用API

### データベース設計
```sql
-- 都道府県テーブル

  id: "prefecture-{name}",
  name: "都道府県名",
  region: "地方区分",
  article_count: "記事数"
}

-- カテゴリテーブル
categories: {
  id: "category-{name}",
  name: "カテゴリ名",
  icon: "FontAwesomeアイコン",
  color: "Tailwindカラー"

-- 記事テーブル
articles: {
  id: "UUID",
  title: "記事タイトル",
  content: "記事内容",
  prefecture_id: "都道府県ID",
  category_id: "カテゴリID",
  author: "投稿者名",
  likes: "いいね数",
  views: "閲覧数"
}
```

## 🎮 使用方法

### 記事の閲覧
1. メイン画面で都道府県またはカテゴリを選択
2. 検索ボックスでキーワード検索
3. 記事をクリックして詳細表示

### 記事の投稿
1. 右上の「記事を追加」ボタンをクリック
2. タイトル、都道府県、カテゴリ、内容を入力
3. 「投稿する」で公開

### フィルター機能
- **都道府県フィルター**: 47都道府県ボタンから選択
- **カテゴリフィルター**: 10カテゴリから選択
- **検索**: リアルタイム検索対応
- **複合フィルター**: 複数条件の組み合わせ可能
